# About This Fork

This is the **Kinolanka Fork** of LinguaCafe, maintained for personal language learning needs.

## What is LinguaCafe?

LinguaCafe is a self-hosted language learning platform focused on vocabulary acquisition through reading. It was created by [simjanos-dev](https://github.com/simjanos-dev/LinguaCafe).

## Purpose of This Fork

This fork exists to:
- Add custom features specific to personal learning needs
- Integrate with custom AI dictionary services
- Test modifications before potentially contributing upstream
- Maintain a stable personal deployment

## Custom Modifications

### AI Dictionary Integration
This fork includes integration with a custom AI-powered dictionary service that provides:
- English definitions (EN→EN)
- Ukrainian translations (EN→UK)
